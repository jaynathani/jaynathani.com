Current focus

Classic SRE assumes a system does the same thing twice. AI systems don't. My recent work adapts reliability practice to that reality.

  1. Agentic Chaos Engineering

    Injecting semantic faults into multi-agent workflows to find the failure modes scripted chaos experiments can't reach.

  2. Safety invariants

    Frameworks that set hard, deterministic blast-radius limits on what automated fixes are allowed to do.

  3. Reliable LLM inference

    Token-aware load balancing and semantic SLOs for distributed inference infrastructure.
